# Real-world examples of each temporal spec

2026-10-20. Do the patterns and scopes of `proposals/temporal-if.md` (Section 3.2) occur in real use? For each spec, a searcher agent looked through system prompts, vendor prompt guides, engineering blogs, conversation-design docs, chatbot laws, forums, chat logs (WildChat, ShareGPT) and papers. An adversary agent then fetched every source and challenged each example on four points: is it real use, does the temporal shape match the spec exactly, does it need state across replies, and does it belong to another spec. The two agents iterated for up to three adversary rounds, until they agreed on every example. Every example below has a verified source and a verbatim quote.

**Verdicts.** STRONG: someone actually gives this instruction to an LLM, or an LLM product or a law requires it, and the temporal shape matches. ACCEPT: real and the right shape, but enforced by app code or not written as an instruction to an LLM. VARIANT: real, but the shape differs in a way that matters (wall-clock time, "at least every k", a different count). REJECT: dropped.

**Do not quote** examples that come from jailbreak prompts or unsafe content: the DAN `[🔒CLASSIC]` rule (ALWAYS), the "AIM" story prompt (AT), the "one question every four responses" persona (EVERY), and PhoxGPT (FROM...UNTIL).

## What this means for the proposal

- Every pattern and scope occurs in real use. The thin ones are AT (mostly structured quiz and audit flows), EXACTLY with free placement, and WITHIN with w > 0.
- EVERY: users mostly write "at least once every k" (a bounded gap), not an exact period.
- AT: the most common real form is n = 1, which the generator excludes.
- FROM...UNTIL: real modes toggle on and off repeatedly. The checker reads only the first segment.
- EXACTLY: in the wild it is "N questions, one per reply" or "once per conversation, tied to an event".
- Real triggers and actions are mostly semantic ("the user sounds dissatisfied", "stay in character"). Literal ones exist ("Classroom Mode", hold/resume, "asdf", "debrief", "niji"), so the benchmark's literal phrases are a controlled subset of real use.
- Quotable motivation: Regal's guide says "Agents have no reliable turn counter". Anthropic's system prompt says "Claude may forget its instructions over long conversations".
